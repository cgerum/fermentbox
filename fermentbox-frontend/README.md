# fermentbox

```
yarn install
```

### Compiles and hot-reloads for development
```
yarn serve
```

### Compiles and minifies for production
```
yarn build
```

### Lints and fixes files
```
yarn lint
```

### Runs unit tests
```
yarn test
```

### Runs unit tests in watch mode
```
yarn test:watch
```

### Runs unit tests with coverage report
```
yarn test:coverage
```
